# 3. Historical analog provenance

Question: which prior dates shape the forecast, and when does a borrowed shape mislead it?

Export retrieved date IDs, lag, distance, retrieval weights and quarter residuals for each evaluated target. Check every source date precedes the reconstruction date and is available under the inference contract. Distinguish engineered analogous-history features from the analog-grid CNN input; inspect owning code before attributing either mechanism.

Using thresholds fixed on selection data, slice performance by analog distance, lag, effective retrieval count and historical regime mismatch. Visualize target hourly curve alongside retrieved curves and residual shapes. Existing success/failure examples motivate hypotheses but are not frequency estimates.

Run frozen-checkpoint diagnostics removing the closest analog or restricting to predefined prior-day windows, recomputing all retrieval-dependent features. Keep selection and calibration unchanged for sensitivity; any changed uncertainty coverage is descriptive. A newly selected retrieval method needs fresh eight-fold fitting/calibration before ranking.

Acceptance: 100% prior-date provenance, complete retrieval audit, monthly sample counts and typical/failure cases; do not label one retrieved day as a causal explanation of the neural output.
