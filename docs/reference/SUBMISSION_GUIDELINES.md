# Neural Wave project submission guidelines

Source: organizer guidelines pasted by the user on 17 October 2026. This is a structured transcription of the requirements for local preparation, not a live organizer announcement. The AET-specific challenge specification also applies.

## Code submission

- Use a structured repository with clear folder names; `src/`, `data/` and `notebooks/` are examples.
- Include a README with the project overview, execution instructions, dependencies and every member's full name, optionally with roles.
- List dependencies in `requirements.txt` or `environment.yaml`; environment setup must work through a simple pip install.
- Follow the challenge's output/API requirements. Noncompliance may invalidate the submission.
- Test in a clean environment. Model entry points must work out of the box; the jury will not debug them.
- Upload to the Neural Wave organization. The generic organizer naming convention is `NW_26_<Company Name>_<Team Name>`; one team member receives collaborator access and can invite teammates.

## Report

Maximum **three pages**, concise and well formatted. Include a brief descriptive project title; approach, methodology, algorithms, architecture, frameworks and motivations; results and key metrics/visualizations; challenges and unsuccessful ideas; transparent AI-agent/LLM assistant usage. Give credit to external sources and avoid plagiarism. The final report will be included in the post-event public repository.

## Video

Maximum **two minutes**. Explain the project goal, relevance, key results and interpretation. Use visuals and, if applicable, a recorded model demo. The jury watches the video first and reads the report second. Prepare a SwissTransfer link containing the video file.

## Final handoff

Check code, report and video for completeness and correct format. **Only one submission per team.** Everything must be correctly published by **11:00 on Sunday** at the latest. In the current 17 October 2026 context, the local working deadline is 18 October 2026 at 11:00 Europe/Zurich; confirm any organizer update. Contact the organizers in person or on Discord if a requirement is unclear.

## Presentation and publication

Prepare a short **five-minute presentation** during judging, or in advance; winners may be asked to present. After the event the repository, including the final report, will be open-sourced.
